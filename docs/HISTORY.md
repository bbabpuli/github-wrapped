## 2026-08-20 — CTA 버튼 (결과 페이지 푸터)

**최종: "나도 해볼래! 🔥" / "I want one too! 🔥"** → 홈 입력창 이동 (lang 유지)

결정 과정과 근거:
- 후보: "내 잔디도 정산하기 🌱" → "다른 계정도?! 👀" → **"나도 해볼래! 🔥"** 확정
- 근거: 밈 확산 시 이 페이지의 주 방문자는 공유 링크로 온 **타인**(카드 주인은 한두 번 보고 끝).
  방문자의 심리("남의 카드 봤다 → 나도 궁금")를 1인칭으로 받아주는 문구가 전환에 유리.
  CTA는 누르는 사람의 목소리로 쓰는 게 정석. "다른 계정 쳐보기" 욕구도 같은 입력창이라 자연 커버.
- 이모지 🔥: streak 섹션(🔥 N일)과 무드 통일 ("잔디 불태우기").
- 위치: 스토리 스택 맨 끝 잉크 푸터, 공유 버튼보다 위·더 크게 (방문자 > 카드 주인 우선순위).
- 추후 실사용 데이터 쌓이면 문구 A/B 재검토 가능 (i18n `makeMine` 키 하나).

## 2026-08-19~20 — 스포티파이 Wrapped 리디자인

- **기각**: 다크네이비 그라데이션 + 에메랄드 + 유리 카드 (전형적 AI 생성 룩)
- **채택**: 라임 팝 — 초고채도 단색 블록 + 초대형 압축 타이포 (실제 Spotify Wrapped 문법)
- 팔레트: 라임 `#D2F65A` · 그레이프 `#4100F4` · 핫핑크 `#F774C4` · 오렌지 `#FF6437` · 잉크 `#121212`
- 타이포: 디스플레이 **Black Han Sans**(한글 지원 초헤비, OG용 TTF를 `assets/fonts`에 번들 —
  `next.config.ts`의 `outputFileTracingIncludes` 필수), 본문 IBM Plex Sans KR
- 결과 페이지 = 색 블록 스토리 스택 (라임 히어로 → 잉크 잔디 → 핑크 카운터 → 그레이프 언어 →
  오렌지 streak → 라임 순위 → 잉크 푸터). 잔디는 잉크 배경 위 라임 스케일
- satori 함정: 자식 2개 이상 div는 `display:flex` 필수 / 한글 소량 텍스트는 런타임에
  Noto Sans KR 글리프 자동 로드로 렌더됨
- "공개 활동 기준 · Public activity only" 문구를 홈·결과·OG 카드 전부에 추가
  (프로필 기여 수와 다른 이유 문의 대응 — 프로필은 비공개 기여 포함)
- `<html lang="ko">` 수정, 입력 예시 bbabpuli → honggildong
